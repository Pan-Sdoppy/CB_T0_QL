# CB_T0_QL — A股可转债 T+0 量化选股

面向个人投资者、针对 **A股可转债（T+0 交易）** 的日频量化选股框架。核心目标：**收益/时间比最大化**——用工业界验证过的 LightGBM 横截面打分，每日选出次日预期收益最高的 Top-N 转债。

- 环境：Python 3.12 + RTX 4070 Ti Super 16GB（torch CUDA 已验证；LightGBM 主模型 CPU 训练仅需数秒，GPU 留作深度模型扩展）
- 数据：akshare → 新浪财经可转债日线，永久缓存到本地 parquet
- 一次全流程（首次下载 1000+ 只约 7 分钟；后续增量秒级）

## 核心规则实现对照

### 规则1 · 数据缓存与异常隔离
- **永久缓存**：每只转债一只 `data/raw/{code}.parquet`，下载后合并去重、保留更长历史。
- **原子写入**：先写 `*.tmp` 再 `shutil.move` 覆盖，中途断电/崩溃不会损坏已有数据。
- **元数据驱动增量**：`data/meta/meta.json` 记录每只券 `latest_date`，启动时秒级判断是否需要更新。
- **单股失败隔离**：每只券独立 try/except，失败记入 `failed_codes` 后继续，不影响全局。
- **智能 skip 窗口**：
  - 工作日：本地落后于预期交易日就发起检查（盘后能拿到当天数据，周一能拿到周五后的数据）；
  - 周末：本地距预期 ≤3 天就跳过，避免周末空跑；
  - **工作日空下载不更新元数据**（盘前运行新浪尚未更新，记录 last_checked 但不动 latest_date，盘后可重试）。
- **预期最新交易日判断**：周一~周五 15:00 后=当天，15:00 前=上一工作日，周末=上周五。
- **死券冷却**：最新数据距今 >180 天视为退市/停牌，7 天内不重复请求。
- 全程 `tqdm` 进度条。

### 规则2 · 每次重训 + 断点保护
- `train.py` 每次从头训练两个模型，不加载旧模型。
- 每个模型训练完**立即原子覆盖保存**到 `models/latest/{backtest,predict}/`，训练中断时旧模型不损坏。
- 训练、回测、预测三个环节各自 try/except，报错写日志后继续，不全盘崩溃。

### 规则3 · 模型覆盖、无垃圾文件
- 一次训练产出两套：
  - `models/latest/backtest/`：用 holdout（最近 120 天）之前的数据训练 → 回测无未来函数；
  - `models/latest/predict/`：用全部最新数据训练 → 实盘预测。
- 每次训练直接覆盖同名 `model.txt` + `features.txt`，不产生版本垃圾。

### 股票池过滤
- 仅保留**已上市**转债（`上市时间` 非空）；
- **次新股**：上市满 60 个自然日；
- 发行规模 ≥ 1 亿、债现价 ≥ 95 元（流动性/违约风险过滤）。

## 策略设计（针对 T+0 转债）

可转债 T+0 但本框架以**日频横截面**起步（工业界个人投资者最稳健的起点）：
- **标签**：次日收益 `close[t+1]/close[t]-1`；
- **特征**（20 个量价因子）：多周期动量、波动率、振幅、位置、均线偏离、量比、偏度峰度；
- **模型**：LightGBM 回归（`num_leaves=63`, LR=0.03, early stopping），每日横截面打分选 Top-5 等权；
- **成本**：双边万 4（佣金万 2 + 滑点万 2，可转债无印花税，符合 T+0 实际）。

后续可在 `src/features.py` 扩展：正股动量联动、转股溢价率、转债-正股相对价值、日内振幅择时等。

## 实测结果（2026-09-25 本机实跑）

| 环节 | 结果 |
|---|---|
| 股票池 | 1059 → 过滤后 1027 只 |
| 数据下载 | 成功 1009 只，76.4 万行（2007~2026-09-24），失败 18 只（已退市/老代码，已隔离） |
| 特征面板 | 70.4 万行，994 只有效 |
| backtest 模型训练 | best_iter=117，约 1.5 秒 |
| predict 模型训练 | best_iter=186，约 1.5 秒 |
| **holdout 回测（120 交易日）** | 累计 +8.96%，年化 +19.7%，夏普 0.44，最大回撤 -27.6%，日胜率 50.8% |
| predict 输出 | 2026-09-24 当日 275 只活跃券选 Top5（金田/胜蓝/赛特/天准/尚太转债） |

> 注：夏普与回撤说明基线策略仍有较大改进空间（需加正股联动、溢价率、波动率择时），但**整条数据→训练→回测→预测链路已在本机完整跑通**，所有规则均按要求落地。

## 常用配置（`config/config.py`）

| 参数 | 默认 | 说明 |
|---|---|---|
| `TOP_N` | 5 | 每日持仓只数 |
| `HOLDOUT_DAYS` | 120 | 回测样本外天数 |
| `MIN_LISTED_DAYS` | 60 | 次新股过滤（自然日） |
| `DOWNLOAD_SLEEP_SEC` | 0.15 | 单只请求间隔（防封 IP） |
| `COMMISSION_RATE` | 0.0002 | 单边佣金+滑点 |
| 环境变量 `CB_LGB_DEVICE` | cpu | 可设 `gpu` 尝试 OpenCL |
